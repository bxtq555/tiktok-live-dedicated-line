美区那两档免中转的差别也值得说清楚。9929 那款回程三网强制走联通 AS9929，去程直连骨干网；GTT/NTT 那款在此基础上换成 192 网段的全新 IP，上游是 NTT（AS2914），主打降低平台风控关联。两款都是 200Mbps 端口、1.5TB 双向流量，差价 4.7 元/月。如果你的号已经被风控打过标记，多花这 4.7 元换网段是有意义的；新号起量阶段，9929 那款够用。

另外提醒一句流量口径：1.5TB 是双向的。直播是长时间持续上行，一小时一小时往上加，跑满一个月和“偶尔播两场”完全是两个用量。选套餐时按你的实际开播时长倒推，别只看端口速率。

## 三个绕不开的疑问

**几十元的 VPS 和 600 元的直播专线，差在哪？**

差在三件事上。带宽是不是独享：WePC 给的是 200Mbps 端口加 1TB 到 2TB 月流量，600 元档给的是 10M 独享。要不要自己配：WePC 的 22 个套餐里 17 个要中转，托管服务把 DNS 落点和出口都配好了。出问题谁负责：VPS 自己运维，托管服务有售后对接。至于推流稳定性谁更强，公开渠道没有同条件对比的实测数据，我不下这个结论。

**标称 200Mbps 能跑满吗？**

端口速率是上限，实际能跑到多少，取决于你的本地网络、中转链路质量、平台推流码率和晚高峰拥塞。挑直播线路时，“能不能长时间稳定跑”比标称数字更值得追问。WePC 的流量双向计费，推流的上行同样算在 1TB 到 2TB 里，长时间开播要按小时折算。

**退款到底怎么算？**

3 天内且流量不超过 10GB，可以全额退到账户余额，或者扣 10 元手续费原路退回。超过 3 天或超过 10GB 任一条，就只能按比例扣掉已用部分退到余额，余额不可提现。所以想拿回现金，只有这一个窗口，测试要在头三天内跑完，别拖。
